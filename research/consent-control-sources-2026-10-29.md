# Optional-service controls — 29 October 2026

The prior banner wrote choices but did not enforce them: Google Analytics/Ads/AdSense loaded unconditionally, custom events ignored the flags, and affiliate SDKs were unconditional. This review changes the actual loaders and event paths, not only banner copy. It is a functional implementation review; it makes no legal-certification or provider-delivery claim.

## Implementation

- Shared `consent.js` validates the exact version2 record, essential flag, three booleans, integer timestamp, future bound and365day expiry. Legacy/malformed/expired records prompt a fresh choice with optional categories off.
- Google tags are absent until analytics or advertising permission. The local stub queues default denied states before any provider configuration; grants update the four consent types. Analytics-only configures GA4; advertising-only configures Ads/AdSense. IDs remain G-2DP7J42ZW0,AW-17246982814,ca-pub-9022308520000198 and the existing click conversion destination.
- Every custom analytics event checks permission at emission. Ads conversion checks advertising independently. There is no pre-consent event replay or navigation callback. Engagement timing starts after consent and excludes hidden-tab time. Custom URL fields remove query/hash/userinfo; native URLs retain original parameters.
- Affiliate classification requires the real partner parameters or recognized affiliate paths. Expedia/GYG policy links do not become click conversions. Native anchors, targets and browser gestures remain independent of optional trackers.
- Three focused booking pages share the same controls. Their consented custom events add fixed landing/offer/placement labels and only a bounded google/bing/not_tagged_paid source marker; raw campaign values and click IDs are not forwarded as custom fields. Display advertising stays absent on these pages even when advertising measurement is chosen. The existing Google click-out conversion is diagnostic, not evidence of a purchase or commission; no purchase event or Microsoft UET ID is invented.
- Accept all, Reject optional, individual Save, persistent Footer control, Close/Escape and focus return are implemented. Optional fields start unchecked. Save returns focus to an external opener or the main landmark rather than a hidden button.
- Withdrawal applies denied signals, Analytics disable flag and removes owned loaders, notifies embed teardown, then reloads. Cross-tab localStorage changes, pageshow, visibility and scheduled expiry refresh state. SessionStorage events cannot reset the consent record.
- Failed localStorage writes cannot automatically reload into a retained older grant. The code attempts removal and records a namespaced **denial-only** tab marker in window.name, preserving/restoring the prior context name. The marker cannot grant permission, even if supplied from another context. A fresh document keeps optional services off and asks again; an explicit in-memory positive choice applies only to the current document. A newer validated durable choice takes precedence. If all persistence methods fail while stale grants remain, no automatic stale-grant reload occurs and the controls instruct clearing site data. The privacy page and conditional status describe the limited durability rather than promising a saved withdrawal.

## Verification and limits

`check-consent.mjs` exercises actual bundled modules and delegated UI handlers: fresh/declined/partial/returning/invalid/expired states, blocked reads/writes, retained old grants across failed withdrawal and a fresh document, denial-only markers, newer cross-tab choice, unrelated storage-area events, all-persistence failure, provider retries, focus return, expiry, visibility and no historical replay. `check-affiliate-navigation.mjs` covers84 partner/tracker/category combinations, negative policy/spoof cases, native parameters/targets/gestures and no callbacks/popups. The embed and cycling suites exercise their actual clients separately.

Browser preview evidence: fresh/rejected state has zero Google or affiliate SDK script elements; stored rejection survives reload. Affiliate-only choice adds the requested SDK(s) with zero Google tags; GetYourGuide creates its real provider iframe. Withdrawal reloads into zero optional scripts/targets/frames. Analytics-only after withdrawing affiliate content loads only the GA4 tag, with no AdSense or booking frames. These are DOM/render observations, not a claim of a complete browser network trace or delivered conversions. No booking or referral click was used to manufacture a conversion.

Booking preview checks at 390px showed no horizontal document overflow. The ad-plan Lake Louise parameters were corrected to the actual stay_base/stay_room/stay_season keys and are now exercised against the real client.

Focused provenance checks prove JS/JSON byte and dirty-revision changes; published photo bytes have separate hash checks. The receipt is a scoped source comparison, not a signature of every deployed asset or condition report.
